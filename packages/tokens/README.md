# @mintelligence-dev/tokens

M-Intelligence brand tokens. **Single source:** [`src/tokens.json`](src/tokens.json)
([DTCG](https://www.designtokens.org/) format). Everything else is generated by `node build.mjs`.

| Output | Use |
|---|---|
| `dist/tokens.css` | Plain CSS variables (`:root`, dark under `.dark` / `[data-theme="dark"]`) |
| `dist/tailwind.css` | `tokens.css` + Tailwind v4 `@theme inline` (`bg-brand`, `text-muted-foreground`, `bg-mintel-blue-600`, …) |
| `dist/fonts.css` | Google Fonts import (Manrope, Rubik, IBM Plex Sans Thai, JetBrains Mono) |
| `dist/index.js` | `import { tokens } from "@mintelligence-dev/tokens"` |
| `dist/shadcn-theme.json` | `cssVars` used by the registry's `mintel-theme` item |
| `lwc/mintelTokens/` | Salesforce LWC CSS-only module |
| `salesforce/mintel-global.css` | Page-level CSS + SLDS styling hooks |

## Palette

| Token | Light | Dark |
|---|---|---|
| `--primary` / `--brand` | `#295DA8` (blue-600) | `#72A3EB` (blue-400) |
| `--brand-accent` | `#7040F2` (purple-600) | `#9E82FF` (purple-400) |
| `--background` | `#FFFFFF` | `#0C0E1E` (neutral-950) |
| `--foreground` | `#181B31` (neutral-900) | `#F9FAFE` (neutral-50) |

Anchors come from the company website and logo. Text/background pairs meet WCAG AA
(e.g. white on `#295DA8` = 6.5:1, white on `#7040F2` = 5.7:1).

> Note: in shadcn, `--accent` is the subtle hover background. The brand purple is `--brand-accent`.

## Motion

| Token | Value | Use |
|---|---|---|
| `--mintel-duration-{instant,fast,base,slow,slower}` | 100 / 150 / 250 / 400 / 600ms | transitions |
| `--mintel-ease-standard` · `--mintel-ease-out` · `--mintel-ease-in-out` | cubic-bezier | `ease-standard`, `ease-ios` in Tailwind |
| `--mintel-ease-spring-{snappy,smooth,bouncy}` | CSS `linear()` spring curve | `ease-spring-smooth` in Tailwind |
| `--mintel-spring-{name}-duration` | settle time of that spring | pair with the curve above |

The same springs are exported for JS so React (motion) and CSS/LWC animations move identically:

```ts
import { tokens } from "@mintelligence-dev/tokens"
<motion.div animate={{ x: 100 }} transition={tokens.motion.spring.smooth} />
```

```css
.panel {
  transition: transform var(--mintel-spring-smooth-duration) var(--mintel-ease-spring-smooth);
}
```

## Glass

`--glass`, `--glass-border`, `--glass-highlight`, `--glass-shadow`, `--glass-foreground` (light + dark) plus
`--mintel-glass-blur` / `--mintel-glass-saturate`. Always provide a solid fallback (`--card`) for
`prefers-reduced-transparency` and browsers without `backdrop-filter`.

## Salesforce LWC

### 1. Component styles — CSS-only module

Copy `lwc/mintelTokens/` into `force-app/main/default/lwc/` and deploy. In any component:

```css
@import 'c/mintelTokens';

.card {
  background: var(--mintel-card);
  color: var(--mintel-card-foreground);
  border: 1px solid var(--mintel-border);
  border-radius: var(--mintel-radius);
  font-family: var(--mintel-font-sans);
}
```

All variables are prefixed `--mintel-*` so they never clash with SLDS `--slds-*` / `--lwc-*`.
Dark mode: set `class="mintel-dark"` (or `data-theme="dark"`) on the component's host element.
The module compiles with `@lwc/compiler` (verified).

### 2. Rebrand base `lightning-*` components — SLDS styling hooks

Upload `salesforce/mintel-global.css` as a Static Resource (e.g. `mintelGlobal`) and load it once:

```js
import { loadStyle } from 'lightning/platformResourceLoader';
import MINTEL from '@salesforce/resourceUrl/mintelGlobal';

connectedCallback() {
  loadStyle(this, MINTEL);
}
```

For Experience Cloud (LWR), link it from the site's head markup instead. The hook names follow the
SLDS docs; verify them against your org's SLDS version (SLDS 1 vs SLDS 2 / Cosmos).

Fonts: Salesforce CSP blocks Google Fonts by default — add a CSP Trusted Site or upload the font files
as a Static Resource. Without them the stack falls back to system fonts.
