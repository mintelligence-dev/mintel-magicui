# Mintel UI for Salesforce

An SFDX project with everything a Salesforce org needs to use the Mintel brand. Deployable as-is.

## Namespace

The project uses the namespace **`mintel`** (`sfdx-project.json`). Component names carry no prefix of their own;
the namespace is the prefix:

| Where | Tag |
|---|---|
| Inside this project (same namespace) | `<c-sla-timer>`, `@import 'c/tokens'` |
| In an org that installed the package | `<mintel-sla-timer>`, `@import 'mintel/tokens'` |

No package version exists yet. Before creating one, the namespace must be registered in a Developer Edition org
owned by M-Intelligence and linked to the Dev Hub. Until then, a direct deploy puts the components in the target
org's default namespace (`c`), where generic names such as `tabs`, `path` or `kanban` could collide with existing
components; `npm run deploy` checks for that and refuses to overwrite them (see Deploy).

| Metadata | What it does |
|---|---|
| `lwc/tokens` | CSS-only module with all Mintel tokens as `--mintel-*` variables (`@import 'c/tokens';`) |
| `staticresources/mintelGlobal` | Page-level stylesheet: tokens + SLDS styling hooks that rebrand standard `lightning-*` components |
| `lwc/brandLoader` | Invisible component — drop it once on a Lightning page to load `mintelGlobal` |
| `lwc/glassCard` | Frosted glass card (`title`, `subtitle`, `variant`) |
| `lwc/shimmerButton` | Brand-gradient button with a light sweep (`label`) |
| `lwc/gradientText` | Animated brand-gradient headline (`text`, `size`) |
| `lwc/statCard` | KPI card with a count-up number (`label`, `value`, `suffix`, `caption`) |
| `lwc/fontSizeControl` | Text-size control ก- ก ก+ for Experience Cloud (`locale`, `applyToPage`); fires `fontscalechange`. Not exposed to Lightning Experience, whose global font size should not change |

`tokens` and `mintelGlobal` are generated by `packages/tokens` (`npm run build:tokens`) — don't edit them here.

## Deploy

```bash
sf org login web --alias my-org
cd packages/salesforce
npm run deploy:check -- --target-org my-org   # only checks for name conflicts
npm run deploy -- --target-org my-org         # checks, then deploys
```

`npm run deploy` first looks for LWC in the org's default namespace with the same names as ours (`tabs`, `path`,
`kanban`, …). Bundles whose description starts with `[Mintel UI]` are ours from an earlier deploy and get
updated; anything else stops the deploy before a single file is written, and lists the conflicts. Any extra
flags are passed on to `sf project deploy start`.

Then, in Lightning App Builder, add **Mintel Brand Loader** once to the app/home/record pages you want rebranded,
and place the other components where you need them. All components are available in the Salesforce mobile app
(`Small` form factor) and in Experience Builder.

For Experience Cloud (LWR) sites, add this to **Settings → Advanced → Edit Head Markup** instead of the loader:

```html
<link rel="stylesheet" href="{basePath}/assets/mintelGlobal" />
```

## Using tokens in your own LWC

```css
@import 'c/tokens';

.panel {
  background: var(--mintel-card);
  border-radius: var(--mintel-radius);
  transition: transform var(--mintel-spring-smooth-duration) var(--mintel-ease-spring-smooth);
}
```

Dark mode: add `class="mintel-dark"` (or `data-theme="dark"`) on the component's host element.

## Mintel brand or the org's theme

By default the Mintel components use the Mintel brand, whatever theme the org has. To make them follow the
org's SLDS 2 theme (Cosmos or a custom theme) instead, opt in:

| Scope | How |
| --- | --- |
| Every Mintel component on a page | Mintel Brand Loader with **Theme = follow-org** (loads the `mintelFollowOrg` stylesheet) |
| One component | `class="mintel-follow-org"` on it, in your own LWC markup |

They then read colors, corner radius and font from the SLDS 2 global styling hooks (`--slds-g-color-accent-1`,
`--slds-g-color-surface-container-1`, `--slds-g-color-on-surface-1`, `--slds-g-radius-border-2`,
`--slds-g-font-family` and others; see `ORG_HOOKS` in `packages/tokens/build.mjs`). In an org without those
hooks they keep the Mintel values. Theme = brand (the default) does the opposite: it loads `mintelGlobal`,
which gives standard `lightning-*` components the Mintel brand.

## Status

All bundles compile with `@lwc/compiler`, and the SLDS hook names are checked against
`@salesforce-ux/design-system` 2.264 CSS. Not yet deployed to a real org — please report anything that behaves
differently in your org (especially SLDS 2 / Cosmos themes).
