# Mintel UI for Salesforce

An SFDX project with everything a Salesforce org needs to use the Mintel brand. Deployable as-is.

| Metadata | What it does |
|---|---|
| `lwc/mintelTokens` | CSS-only module with all Mintel tokens as `--mintel-*` variables (`@import 'c/mintelTokens';`) |
| `staticresources/mintelGlobal` | Page-level stylesheet: tokens + SLDS styling hooks that rebrand standard `lightning-*` components |
| `lwc/mintelBrandLoader` | Invisible component — drop it once on a Lightning page to load `mintelGlobal` |
| `lwc/mintelGlassCard` | Frosted glass card (`title`, `subtitle`, `variant`) |
| `lwc/mintelShimmerButton` | Brand-gradient button with a light sweep (`label`) |
| `lwc/mintelGradientText` | Animated brand-gradient headline (`text`, `size`) |
| `lwc/mintelStatCard` | KPI card with a count-up number (`label`, `value`, `suffix`, `caption`) |

`mintelTokens` and `mintelGlobal` are generated by `packages/tokens` (`npm run build:tokens`) — don't edit them here.

## Deploy

```bash
sf org login web --alias my-org
cd packages/salesforce
sf project deploy start --source-dir force-app --target-org my-org
```

Then, in Lightning App Builder, add **Mintel Brand Loader** once to the app/home/record pages you want rebranded,
and place the other components where you need them. All components are available in the Salesforce mobile app
(`Small` form factor) and in Experience Builder.

For Experience Cloud (LWR) sites, add this to **Settings → Advanced → Edit Head Markup** instead of the loader:

```html
<link rel="stylesheet" href="{basePath}/assets/mintelGlobal" />
```

## Using tokens in your own LWC

```css
@import 'c/mintelTokens';

.panel {
  background: var(--mintel-card);
  border-radius: var(--mintel-radius);
  transition: transform var(--mintel-spring-smooth-duration) var(--mintel-ease-spring-smooth);
}
```

Dark mode: add `class="mintel-dark"` (or `data-theme="dark"`) on the component's host element.

## Status

All bundles compile with `@lwc/compiler`, and the SLDS hook names are checked against
`@salesforce-ux/design-system` 2.264 CSS. Not yet deployed to a real org — please report anything that behaves
differently in your org (especially SLDS 2 / Cosmos themes).
